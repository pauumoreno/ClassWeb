## Overview

ClassWeb is an academic Model-Driven Development (MDD)
project developed as part of the Software Engineering
degree at Universidad Politécnica de Madrid (UPM).

The project focuses on designing a Domain-Specific
Language (DSL) and automating code generation from
visual software models.

## Features

- Domain-specific language design
- Visual modeling of classes and relationships
- Custom graphical modeling tools
- Automatic HTML code generation
- Automatic Java class generation
- Code generation through T4 templates

## Technologies

- C#
- T4 Text Templates
- Visual Studio Enterprise 2022
- Microsoft DSL Tools
- HTML and CSS
- Java
- Git and GitHub
